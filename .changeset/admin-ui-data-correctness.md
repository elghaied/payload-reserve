Fix admin calendar/availability data correctness. The month view now fetches the full 6-week (42-cell) span it renders, so trailing weeks are no longer silently empty. The Availability Overview honors exception `endDate` ranges (a multi-day time-off now blocks every day in the range, not just the first). Calendar and overview fetches guard against stale responses so rapid navigation can't render an older result over a newer one. The CustomerField now builds its URLs from the configured API route/server URL instead of a hardcoded `/api`, so custom `routes.api` or base-path deployments work. The dashboard widget's stats use count queries instead of a 100-document fetch, so they stay accurate on busy days. The week/day/lane views derive their visible-hour window from the day's bookings (clamped to a sensible default) and share one window, so a booking outside business hours is shown rather than hidden and the three views agree. List fetches were raised to a safe ceiling with a "showing N of M" notice when exceeded, the pending-count badge and dashboard use count queries instead of downloading every document, and the availability grid no longer caps busy intervals at 500.
